#### R1 · Redis 任意跳页
- **现状**：`redis.js` `getPageData`（`redis.js:151`）与 `getKeyDetail`（`redis.js:206`）用游标模型（非 offset），UI 仅顺序 prev/next（`db-session.jsx` Redis 详情 `:5515/5584/5634`）。SCAN cursor 不透明，不能用 `(page-1)*pageSize` 当游标（会重复/遗漏，`redis.js:146-149` 已注释）。
- **方案**（SCAN 无 offset，须前向扫到目标游标）：
  1. **已加载区间内存缓存**：prev/已访问页即时回跳，不重新请求。
  2. **跳页输入**：用户输入目标页码 → 从 `cursor=0` 前向 `SCAN` 步进到 `targetPage*pageSize` 位置（O(N) 扫描，带 loading + 可取消）；超大键（百万字段）给出「跳页将扫描全量，可能较慢」告警 + 可选「仅在前 N 万内跳」。
  3. **折中策略**：首次全量 SCAN 入内存（中小键体验最佳），超阈值（如 5 万）改前向扫描跳页。
- **改动点**：`redis.js` 新增 `scanToCount`（复用游标循环，参照 `:192 scanPage`）；`db-session.jsx` Redis 详情区加「跳至第 N 页」输入 + 缓存 state。
- **风险**：中（SCAN 主循环 + UI + 缓存一致性）。
- **排期**：约 1 周（含超大键阈值策略 + CDP 真库 Redis 复测）。
- **✅ 已完成（2026-10-28 重做，待服务环境 CDP 真库回归）**：
