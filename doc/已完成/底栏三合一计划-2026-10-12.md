# 底栏三合一计划（statusbar + footer + app-kbar → 一条 36px 底栏）

> **状态：✅ 已完成（2026-10-21 复核）**：底栏三合一已落地（footer/quick-cmd-strip 等），本文仅作历史设计留存。

## Context
用户红框反馈底部三条横条（kbar 30px / footer 36px / statusbar 26px，共 92px）冗余，要求"统一合并到底栏"。已确认形态：**三条合一条 36px** —— 左区会话状态（原 statusbar），右区全部按钮（kbar+footer 去重，AI/快捷命令/命令历史 3 个重复按钮保留 footer 版）。合并后终端区净增 56px 高度。

关键核实结论：
- `window.refs`（common/ref.js L2 Map 单例）与挂载点无关 → footer **保持 layout.jsx L207-210 挂载不动**
- `--right-panel-dock-width` 唯一消费者是 app-kbar/index.styl → kbar 删除后该变量整体退役
- store.js L183 `inActiveTerminal` 门控只管 footer 空条分支 → **状态区与全局动作组必须放门控之外**（kbar/statusbar 原本常显）
- e2e 0061 断言 monitorBottom≈footerTop 因 statusbar 26px 当前隐性失败，合并后自动修复
