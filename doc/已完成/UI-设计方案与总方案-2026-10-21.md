### 1. 设计体系（三层，已落地）

#### L1 · token 派生层（`src/client/css/includes/tokens.styl`）

- 颜色**全部由基色派生**（`color-mix`），不新增 `requiredThemeProps` → **12 主题自适应红线**；
- 圆角四档 `--radius-xs 4 / sm 8 / 10 / lg 14 / pill 999`；动效 `--dur-1 120ms / --dur-2 180ms / --ease cubic-bezier(.4,0,.2,1)`；
- 表面阶 `--surface-0/1/2/3`；交互 `--hover-bg / --active-bg / --border`；字体 `--font-mono`（**注意不是 `--mono`**）；
- **Stylus 约束**：含 `in` 的 `color-mix(...)` 必须 `unquote()` 包裹（否则编译失败且产物不更新）。

#### L2 · 统一层

- 收敛圆角/阴影、修复 antd 桥接（`uiThemeConfig`）、动效基线（22→30 文件覆盖）、焦点可见性基线、`prefers-reduced-motion` 全局兜底、CJK 字体回退、`darker()` 非法色修复。

#### L3 · v4「Tinted Console」深度层

- 主色**低比例混入中性底**（`4%/2%/6%`）形成"带色控制台"质感；强调用**低对比底色 + 品牌色**，避免整行实心主色。

## 2. electerm UI 重设计方案 · v5（整体重构版）

> 原文档：`UI-重设计方案-2026-10-14.md`（2026-10-14）

> **状态：✅ 已完成（2026-10-21 复核）**：v4/v5 重构已落地。

> 定位：在**允许调整 UI 结构**的前提下，对 electerm 主界面做一次系统性重绘，解决"**粗糙、简陋、不好看**"。
> 配套高保真草图：`UI-重设计草图-2026-10-14.html`（整体真实界面，可切换暗/亮主题与终端/文件/首页视图）。
> 与旧版关系：保留 `UI-美化设计规范-2026-10-14.md` 的 **token 派生**思路与 12 主题兼容底线，但**放开布局/DOM 约束**。

---

### 一、为什么"显得粗糙"（现状诊断）

| 症状 | 根因 |
| --- | --- |
| 层级扁平、无纵深 | 全库仅 15 个颜色变量，**无阴影/圆角/间距/动效 token**（`theme.styl` 仅 16 行） |
| 圆角/阴影杂乱 | 12 种圆角、22 种阴影写法，视觉语言不统一 |
| 界面"干"、"空" | 信息密度与留白失衡：标签栏/侧栏无层次、终端上下无承载 |
| 无状态反馈 | 67 个 `.styl` 中仅 8 个有 `transition`，几乎零动效 |
| 品牌感弱 | 无强调色运用、无光晕/渐变点缀，与竞品（Warp/Linear/Termius）差距明显 |
| 结构陈旧 | 标签栏与标题栏混排、侧栏单一、缺命令面板/状态栏等现代范式 |

### 二、设计原则

1. **分层**：底（`--s0`）→ 内容（`--s1`）→ 浮起（`--s2`）→ 更高浮起（`--s3`），用色阶而非边框堆叠制造纵深；
2. **克制的强调**：`--primary` 只用于"选中/焦点/品牌点缀"（≤10% 面积），配一次 `--glow` 光晕；
3. **统一节奏**：圆角 4 档、阴影 3 档、动效 2 档时长 + 1 条缓动；
4. **信息密度**：行高/内边距统一 4px 栅格，终端等宽字体独立节奏；
5. **主题无关**：所有颜色 `color-mix` 派生，**12 主题 + 亮/暗自动适配**，不新增必填主题变量。

### 三、信息架构（结构重设 · 与现状的差异）

```
┌ 标题栏 (38px)  Logo · 工作区名 · [⌘K 命令入口] ………… [− □ ×]      ← 新增全局命令入口
├ 标签栏 (38px)  ● ubuntu-prod × | ● db-primary ② × | +            ← 独立成行 + 状态圆点/计数
├ 左图标栏 (50px) 会话/文件/隧道/书签/传输/设置 · 头像              ← 新增"图标栏"层级
├ 左面板 (236px) 会话树（分组 + 在线状态 + 协议标签）                ← 面板可折叠
├ 内容区                                                             ← 新增"面包屑"承载连接信息与操作
│   面包屑(32px)  host · user@ip · [已连接][SSH/zsh][●REC] | 分屏/SFTP/AI
│   视图：终端 / 文件(双栏) / 首页(聚合)
│   快捷键条(30px) ⌘K · ⌘⇧F · ⌘⇧S · ⌘I · ⌘R · ⌥T
├ 右面板 (308px) [AI | 传输 | 监控] 页签                            ← 由"单一右栏"改为多页签
└ 状态栏 (26px)  连接态 · 加密算法 · shell · 编码 · 速率 · ⌘K 提示    ← 新增
悬浮：命令面板 (⌘K, 520px)                                          ← 新增现代范式
```

**相对现有布局的改动**：① 顶栏加全局命令入口；② 标签栏独立成行且有状态语义；③ 左栏分为"图标栏 + 会话树"两级；④ 内容区顶部加面包屑；⑤ 新增快捷键条与状态栏；⑥ 右栏页签化；⑦ 新增命令面板与首页聚合。

### 五、视觉语言（token 体系）

> 全部由既有 12 基色派生，**不新增 `requiredThemeProps`**（否则主题编辑器保存失败）。

```styl
/* 色阶 */
--s0: color-mix(in srgb, var(--primary) 5%, var(--main-dark))   // 最低层：标题栏/侧栏
--s1: color-mix(in srgb, var(--primary) 2%, var(--main))        // 内容层
--s2: var(--main-light)                                          // 浮起：菜单/弹窗
--s3: color-mix(in srgb, var(--text) 6%, var(--main))           // 输入/更高浮起
/* 线/交互 */
--bd:  color-mix(in srgb, var(--text) 12%, transparent)          // 常规分隔
--bds: color-mix(in srgb, var(--text) 22%, transparent)          // 强分隔/输入框
--hov: color-mix(in srgb, var(--text) 7%, transparent)           // hover
--act: color-mix(in srgb, var(--primary) 16%, transparent)       // 激活/选中底
/* 品牌 */
--glow: 0 0 0 1px color-mix(in srgb,var(--primary) 45%,transparent),
        0 2px 16px color-mix(in srgb,var(--primary) 28%,transparent)
/* 状态底 */
--ok-bg/--err-bg/--warn-bg/--info-bg: color-mix(in srgb, <状态色> 15%, var(--main))
/* 圆角 4 档 */
--r-xs:4px  --r-sm:8px  --r:10px  --r-lg:14px  (--r-pill:999px)
/* 阴影 3 档 */
--sh1:0 1px 2px rgba(0,0,0,.28)  --sh2:0 6px 18px rgba(0,0,0,.34)  --sh3:0 30px 80px rgba(0,0,0,.6)
/* 动效 */
--dur:120ms  --dur2:200ms  --ease:cubic-bezier(.4,0,.2,1)
/* 字体 */
--font: 系统 UI 栈(含 CJK 回退)   --mono: SF Mono/JetBrains Mono/Consolas(含 CJK 等宽)
```

**用法红线**：`--primary` 面积 ≤10%；分隔一律用 `--bd`（1px）或 `inset box-shadow`（避免布局位移）；状态色只出现在语义处。

### 六、组件规范（要点）

| 组件 | 规范 |
| --- | --- |
| 标签 | 32px 高；状态圆点（绿/红/灰）；hover `--hov`；激活 `--s1` + 1px 主色内描边 + 顶部 2px 渐变线 |
| 会话节点 | 8px 圆角；在线圆点；协议 `tag` 等宽；激活左 2px 主色条 + `--act` 底 |
| 按钮 | 主 `--primary`；次 透明+`--bds` 描边；hover 位移 1px + 阴影；禁用 40% 透明 |
| 输入 | 底 `--s1`，边框 `--bd`，聚焦 `--primary` 55% 边框 + 2px `--act` 外环 |
| 卡片 | `--s1` 底 + `--bd` 边 + `--r`；hover 边框转主色线 |
| 徽标 | `ok/live` 用状态底；REC 用 `--err-bg` + 呼吸点 |
| 命令面板 | 520px、`--s2`、`--r-lg`、`--sh2`；项高 36px，选中 `--act` |
| 进度条 | 高 6px、`--r-pill`、主色渐变；超阈值转 warn→error 渐变 |

### 七、交互与动效

- **时长**：微交互 `--dur`(120ms)，浮层/面板 `--dur2`(200ms)，同一条 `--ease`；
- **属性**：只动 `background / color / border-color / transform / box-shadow / opacity`（合成友好）；
- **焦点**：全局 `:focus-visible` 描边环（2px `--act` + 1px 主色），键盘可达；
- **降级**：`@media (prefers-reduced-motion: reduce)` 关闭位移与呼吸动画；
- **命令面板**：`⌘K` 唤出，支持主机/动作/命令模糊搜索；`⌘⇧D` 预留数据库入口。

### 八、主题与响应式

- 暗色为默认；**亮色必须通过** `data-theme="light"` 覆盖 12 基色，派生层自动跟随；
- 对比度红线：正文 ≥ 4.5:1（现状 `--success` 在浅底仅 1.61:1，**必须修**）；
- 窄屏（<800px）：左面板折叠为图标栏悬浮、右面板改为抽屉；标签栏可滚动。
