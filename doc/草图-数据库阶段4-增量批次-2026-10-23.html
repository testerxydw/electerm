§实施约束（与设计文档对应）

  • 不引入重依赖：补全/导入解析/导出生成均零依赖自写（对齐 db-sql-format.js / db-csv.js 先例）；编辑器引入 CodeMirror 6（ESM，vite 手动 chunk，dist 增量 ≤150KB）。
  • 不改现有度量：网格行高/工具条高度/圆角全部沿用 token；新控件只用既有 token 与 :focus-visible 规范。
  • IPC 纪律：新增通道仅 dbSqlFavoriteOp；导出/导入走 dbClientOp 扩 OP_MAP + 轮询状态 op；入参一律 clone。
  • 只读权威仍在主进程：导入/Redis 写/表设计器类操作全部 checkWritable 前置；渲染层传 readOnly:false 无效。
  • 代码借鉴纪律：dbgate（GPL-3.0）仅参考架构；antares / ARDM（MIT）、DBeaver / DBX（Apache-2.0）可改编代码，头部保留 attribution 与 NOTICE；Navicat 闭源，仅参考交互流程，不复制其资源与文案。
  • 补全不做网络请求：列信息在切库时一次拉取并缓存；三层解析（词法/源解析/场景）任何一层失败都降级为"全量候选"，不允许静默不弹。
  • CM6 引号前缀坑（DBX #12008）：补全替换区间含起始引号时，候选需 filter:false 并自带 match，否则菜单会被 CM6 自身 matcher 清空。
  • 写操作两道闸：前端分级（read/write/ddl/dangerous/transaction/unknown）→ 危险确认；手写 WHERE / 转换器表达式 → 主进程 assertSafeClause 二次校验（禁分号/注释/语句关键字/非白名单标识符）。
  • E2 契约变更：getPageData 扩参 where / whereParams / orderBy / count；C 批导出复用同一条件（所见即所导），因此 E2 必须先于 C。构建器只产出占位符 + whereParams，值永不拼进 SQL。
  • F0 向后兼容：describeTable 只增字段不改语义（column_name / is_primary_key 等沿用），老前端不改也能跑；视图节点 type:'view' 在主进程与渲染层双重禁写。
  • F3 二进制：safeCell 输出 { __bin: { size, b64, truncated } } 信封；禁止再把二进制转成 <binary N bytes> 字符串（当前导出即丢数据）；全量取用独立 op getCellBinary。
  • F2 连接纪律：手动事务最多 2 个 tab（pool 4 条连接），空闲 10 分钟自动回滚，关 tab / 关窗强制回滚；pinned 期间该 tab op 串行。
  • G1 广播三闸：密码提示期（复用 _passwordPromptDetected）不镜像、OSC 应答不镜像、目标含 production 书签须手输主机名确认；扇出只在 sendToServer 单一入口，用 _broadcastDepth 防环。
  • G3 读文件上限：新增 readRemoteFileChunk（默认 2MB），不允许用现有 readRemoteFile 全量读做预览；PDF 不内嵌，只给下载入口。
  • G4/G5 路径安全：归档与镜像所有远端路径走 shellQuote + 拒绝换行 + -- 终止选项；镜像"删除远端多余文件"默认不勾。
  • G6 密钥层次：保留 AES-256-GCM（不降级 CBC），主密码 → KEK → 包裹随机 DEK；主密码不落盘、密钥只在主进程内存；迁移中断必须可回滚。
  • G 批与 A~F 解耦：G 批只改 terminal/ sftp/ file-transfer/ server/，与数据库线唯一交叉点是 production 语义（E1 定义、G1/G5/G6 复用）。
  • 每批独立提交：feat(db): xxx (阶段4-X) / feat(core): xxx (阶段4-GX)，附单测数量；不混批。
