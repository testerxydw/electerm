## 2. electerm 数据库模块现状快照（源码核对，2026-10-22 扩展批次后更新）

- 后端 op 白名单（src/app/lib/db-client/index.js OP_MAP）：
  mysql/pg = getMetadata / getPageData / describeTable / updateCell / **insertRow / deleteRows** / countRows / executeSql；
  redis = getMetadata / getPageData / getKeyDetail / setKey / delKey / expireKey
- 前端：元数据树(库/表/schema) + 树筛选(T2)、数据网格(排序/分页/过滤/编辑/滚动统一 +
  **行选择/添加行弹窗/批量删除(B1)**)、SQL 编辑器(textarea + **格式化 A3**)、
  值预览(db-value-pane 含 JSON 格式化)、CSV/JSON/SQL 导出菜单(S3-B+A4)、
  **复制为 INSERT/UPDATE/JSON/TSV(A1)**、**DDL 查看(A2，mysql 系)**、执行历史(S3-C)、
  **URI 快速连接(A5)**、只读模式、Redis 键空间、PG 跨库连接入口
- 详见 doc/设计-数据库阶段3-2026-10-22.md §7.9 实施完成记录（测试基线 1454，包 test.239）
- 设计储备未实施：T6 WHERE 下沉、T10 国产库、T12 Redis 类型化写、全表流式导出
