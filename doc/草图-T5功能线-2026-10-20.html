③ 终端会话录制 REC 指示 T5-4 新增

⌘R（Mac）/ 设置页可配置 开始/停止录制；asciinema v2 格式落盘 ~/Downloads，默认仅录输出不录键盘输入。
终端右上角浮层（录制中）+ 停止后 toast
➜ electerm git status

nothing to commit, working tree clean
➜ electerm ▊

已保存：~/Downloads/electerm-rec-20261020-223015.cast （点击复制路径）
落点：浮层 absolute 于终端区右上角（session-wrap 内），不动 flex 布局；红点用 danger 色派生 token，闪烁动画带 prefers-reduced-motion 兜底。
行为：点击浮层 = 停止录制并 toast 文件路径；开始录制同样 toast；tab 关闭自动停录并 flush 最终缓冲。
隐私边界：仅记录输出事件 'o'（asciinema v2 JSONL），不记录键盘输入；缓冲 500ms / 256KB 批量写，长会话内存有上限。

④ 快捷键设置页新增条目 T5-4a

shortcuts-defaults.js 注册 terminal_toggleSessionRecord，设置页列表自动出现（buildConfig 驱动，无需改设置页代码）。
清屏 terminal_clear ⌘L
开始/停止会话录制 terminal_toggleSessionRecord ← 新增 ⌘R
重新加载当前标签 app_reloadCurrentTab AltR （与录制键不冲突）
绑定边界：Win/Linux 默认不绑定（Ctrl+R 是 shell 反向历史搜索，不可劫持）；仅 Mac 默认 ⌘R（meta 前缀不透传 shell）。alternate buffer（vim/TUI）下 handleKeyboardEvent 直接放行 xterm —— 录制开关在 TUI 内自然失效，属预期行为。
