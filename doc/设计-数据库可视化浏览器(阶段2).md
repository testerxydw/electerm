## 1. 竞品调研摘要

| 工具 | 核心形态 | 可借鉴 |
|---|---|---|
| Navicat | 左侧连接树（库/表/视图）+ 对象网格 + 多标签 SQL 编辑器 + 行内编辑 | 树+网格+SQL 三区布局 |
| DBeaver（开源） | 元数据树 + SQL 多标签 + 结果多网格 + ER 图 | 每查询一个结果网格；只读连接开关 |
| TablePlus | 轻量三区，快捷键驱动 | 分页浏览 + 行内编辑门槛低 |
| RedisInsight / ARDM | 键空间树（SCAN）+ 类型化键详情 + TTL/控制台 | Redis 需专属形态，不能套 SQL 网格 |

结论：采用 **Navicat 式三区布局**（元数据树 / 数据网格 / SQL 编辑器）；Redis 单独按键空间形态设计。

### 4.2 页签内布局（db-session.jsx，lazy 加载）
```
┌────────────┬──────────────────────────────────┐
│ 元数据树    │  Tabs: [数据] [SQL查询] [表结构]    │
│ (antd Tree)│  数据:   antd Table 分页网格       │
│ 库 → 表/视图│  SQL:   编辑器 + 执行按钮 + 结果网格│
│ 工具条:刷新 │  结构:   列定义表格                │
└────────────┴──────────────────────────────────┘
```
- 树：库 → 表/视图（懒加载展开），点击表 → 右侧打开该表数据 tab
- 网格：antd Table，服务端分页（LIMIT/OFFSET），列排序（ORDER BY），MVP 只读展示
- SQL 编辑器：MVP = textarea + Ctrl/Cmd+Enter 执行 + 结果网格（多语句多结果集 tab）；CodeMirror6 语法高亮列二期
- Redis 特化：树=db0~db15 → SCAN 分页键列表；详情按 string/hash/list/set/zset 类型化展示 + TTL 显示；MVP 键详情只读 + 删除/改 TTL

### 4.3 主进程扩展（src/app/lib/db-client/）
统一接口（各引擎适配器实现）：
```
getMetadata()        // 库列表/表/视图（树数据）
getPageData({table, page, pageSize, orderBy, order}) // 分页数据
describeTable(table) // 列结构
executeSql(sql)      // SQL 执行（返回 {fields, rows, affected}）
close()              // tab 关闭时断开
```
- index.js 从 `testDbConnection` 扩为 `getDbClient(dbBookmark, sshBookmark)` 工厂：建连接（含隧道，复用 db-tunnel）并返回带上述方法的实例；连接实例缓存按 tab.id 管理
- 生命周期：tab 打开 → 懒建连接；tab 关闭（delTab 钩子）/ app 退出 → close 断开，防连接泄漏
- 保活：mysql2 enableKeepAlive；ioredis keepAlive 由 TCP 层
- 断线：操作报错时 UI 顶栏显示断开提示 + 重连按钮（重建 client）

### 4.4 IPC 与安全
- 渲染层经 `window.pre.runGlobalAsync('dbClientOp', { tabId, op, args })` 调用（复用 trusted-sender 的 asyncGlobals 通道，无需新增 ws 通道）
- 只读防护（决策点 D1）：可选只读模式（连接配置开关，默认开）——主进程对 executeSql 做白名单校验（仅 SELECT/SHOW/DESC/EXPLAIN）；Redis 只读命令白名单（GET/HGETALL/LRANGE/SMEMBERS/ZRANGE/SCAN/TTL/TYPE）
- 大表防护：网格强制分页，单页上限 1000 行；无主键表提示只读

## 6. 风险与回滚

| 风险 | 等级 | 缓解 |
|---|---|---|
| 连接泄漏（tab 关闭未断开） | 中 | delTab 钩子强制 close + app 退出兜底清理 |
| 大结果集卡 UI | 中 | 服务端强制分页 1000 行上限 |
| 只读校验被绕过 | 低 | 白名单在主进程侧执行，渲染层仅传参 |
| session.jsx 分支影响既有类型 | 低 | 独立 if 分支 + lazy，回归跑 SSH/SFTP/web |
| 上游合并冲突 | 低 | 新增目录为主；session.jsx 仅 +4 行 |

回滚：revert 对应提交；阶段1 数据结构不变。
