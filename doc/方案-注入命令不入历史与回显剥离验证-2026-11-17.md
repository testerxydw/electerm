# 注入命令不入历史 + 回显剥离实机验证

日期：2026-11-17　状态：已完成（探针 11/11 全绿，全量回归见文末）

## 背景

用户实测（RHEL 系 root 远程 ssh）：注入命令 `eval '...'` 出现两处污染 + 回显剥离未生效。

1. electerm 命令历史出现整条注入行。
   成因：bash `__e_pre`（shell.js:44）排除列表不含 `eval` 行本身，DEBUG trap 首触发
   `BASH_COMMAND` = 整条注入行 → 上报 633;E → command-tracker 入历史；zsh/fish 的
   preexec 钩子（shell.js:66/87）同样无差别上报。
2. bash 内存 history 出现注入行。
   成因：注入行带前导空格，但主机 HISTCONTROL 不含 ignorespace（RHEL 默认
   ignoredups）→ 记入。
3. 回显剥离未生效：上一次修复（7f2b3d78）只改 src/，未跑 npm run compile，
   用户实测跑的是旧 bundle（work/app）。

## 方案（三层堵，指纹收窄为注入行专属签名）

**指纹判据**：`*"eval 'if [["*ELECTERM_SHELL_INTEGRATION*` 双标记——只有注入行自身
同时含 `eval 'if [[`（wrapSilent 的 eval 包装）与 `ELECTERM_SHELL_INTEGRATION`。
初版宽匹配（仅指纹串）在探针上暴露误杀：用户命令文本里只要提到该环境变量名
（如 `echo $ELECTERM_SHELL_INTEGRATION`）就会被 `__e_cmd` 从 bash history 里删掉、
被 tracker 丢出 electerm 历史——故收窄。

1. 远端脚本排除（治本，防 633;E 上报）：
   - bash `__e_pre`：`[[ "$BASH_COMMAND" == *"eval 'if [["*ELECTERM_SHELL_INTEGRATION* ]] && return`
   - zsh `__e_preexec` / `zshaddhistory` 同形（zshaddhistory 返回非零 = 不入史）
   - fish `__e_preexec` 保持宽指纹（fish 注入无 eval 包装，双标记不适用；fish 无
     history 自删路径，误伤面只剩 633;E 上报，可接受）
2. history 兜底：
   - bash：`__e_cmd` 每个 prompt 检查 `history 1` 末条，命中签名才 `history -d`
     （一次性标记会被 bash 启动首 prompt 消耗掉，必须逐 prompt 检查）
   - zsh：`zshaddhistory` 对签名行返回非零
3. 客户端兜底：command-tracker 收 633;E 时过滤含双标记的命令（防用户自配旧版脚本）。

另有 attach-addon-custom writeToTerminal 补丁（同 commit）：结束抑制窗口的那个
chunk（含首个 633）不再 fall-through 原样写屏，而是推入抑制缓冲统一回放——pty 把
注入回显与首个 633 合并进同一帧（本地 pty 很快，常见）时旧代码会整帧漏出回显。

## 实机探针结论（run 9355，11/11）

- 注入回显与首个 633 同窗到达（chunk 2=1104B echo、chunk 3=71B 633，均 sup=1），
  replay 剥离后屏上无注入行（buffer 扁平化后无 `eval 'if [[`）
- bash 执行注入（PC_YES_2）；history -w dump 无注入行；提及指纹串的真实命令保留
- electerm 命令历史无注入行；真实命令经 633;E 正常上报（reportedNow=true）
- 时序注意：探针 tap 必须在注入开始前挂好（TAPCHECK 延迟一步），否则抓不到窗口
  内数据流——早先几轮"shellInjected=false/回显上屏"半数是探针自身时序/判据假阳性

## 七维取舍

功能：双标记误伤面≈0（需同时含 eval 'if [[ 与指纹串，实为重跑注入的场景，本就该排除）。
性能：注入脚本 +~300 字节，单次连接一次性。
可靠性：history 禁用（HISTSIZE=0）时自删静默容错；zshaddhistory 覆盖用户自定义
钩子的风险用注释声明（罕见）。
兼容性：bash here-string 需 bash≥2.05b（RHEL 7 bash 4.2 OK）；fish 本次不动。
