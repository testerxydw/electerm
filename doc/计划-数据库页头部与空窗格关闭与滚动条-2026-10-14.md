## 一、需求 1：数据库页顶部控制条

### 1.1 现状（红框里是什么）

- 数据库 tab 顶部显示的是**终端用的会话控制条** `SessionControl`：
  - 渲染点 `src/client/components/session/session.jsx:653-659`，其中 `isNotTerminalType` 由 `session.jsx:381-389` 计算；
  - `session.jsx:381` 的白名单只含 rdp/vnc/web/telnet/ftp/spice → **不含 `terminalDatabaseType`**，所以数据库 tab 也走了终端分支；
  - `session-control.jsx:59` 只对 `isNotTerminalType` 返回 null；对数据库 tab 会渲染 `renderConnInfo()`（`本地` + 状态胶囊 `未连接`）与 `renderPaneControl()`（pane 切换 `终端`，数据库没有 SFTP/文件管理，纯噪音）。
- 结果：截图红框 = `本地 | 未连接 | 终端` + 下方树头的 `redis` 引擎名 + 只读开关 + 刷新，**两行信息重复且与数据库无关**。
- 之前**没有**针对这个区域的专门设计：已有的是 tab hover 提示（`c42fc69b` 前的 `412c12d9`）与连接失败卡片（`c5edb07e`），都不覆盖这条顶栏。

### 1.2 设计（推荐 A：把该条改造为「数据库工具条」）

```
┌──────────────────────────────────────────────────────────────────────┐
│ [Redis] 192.168.115.67:6379 · db1 · root        ● 已连接   ⟳  只读 ⬤ │  ← 32px，与原控制条同高
├────────────┬─────────────────────────────────────────────────────────┤
│ 树（无树头）│  数据 / SQL / 结构                                        │
└────────────┴─────────────────────────────────────────────────────────┘
```

- 左：引擎徽标（`dbTypeLabelMap`）+ `host:port` + 库 + 用户（复用 `db-conn-error.jsx` 的 `dbTargetText(tab)`），空值自动隐藏；
- 中：状态点 + 文案（已连接 / 未连接）+ 未连接时显示「重连」；
- 右：刷新（重载元数据树）+ 只读 `Switch`（保留 Tooltip：`readOnlyHint`）；
- 树头 `.db-tree-head` 里的引擎名/只读开关随之移除（刷新移到工具条），消除重复行。

**高度口径**：`computeHeight = height - tabsHeight - termControlHeight(32)`（`session/sessions.jsx:31-38`、`common/constants.js:30`）。新工具条同样 32px 并占用**同一位置**，所以不引入新的高度扣减（避免再次出现"内容伸到底栏之下"）。

### 1.3 备选

| 方案 | 内容 | 评价 |
| --- | --- | --- |
| **A（推荐）** | 改造为数据库工具条（引擎/目标/状态/重连/刷新/只读） | 信息对得上、空间不浪费 |
| B | 直接隐藏该条（数据库页不要顶栏），树头保持现状 | 改动最小，但只读/刷新仍挤在树头 |
| C | 只保留"状态 + 重连"，其余不动 | 半成品，仍与树头重复 |

## 二、需求 2：空窗格关闭按钮（既有设计可落地）

- 现状证据：`layout.jsx:129-176` 每个窗格都渲染 `TabsWrap`；`tabs/index.jsx:577-585` 在**该窗格**无 tab 时渲染 `renderNoSession()` → `no-session.jsx`（只有 新建/书签/AI/QuickConnect/历史，**没有关闭入口**）；`store` 侧无 `closePane/closePanes`（全仓库零命中）。
- 关掉某窗格最后一个 tab 后 `store.layout` 与窗格数都不变（`store/tab.js` 的 `fixCurrentTabIds` 只修 activeTabId）→ 空窗格长期占位。

### 2.1 推荐实现（沿用 `doc/设计-分屏空窗格关闭方案-2026-10-14.md` 的方案 A）

1. `store/tab.js` 新增 `closePane(batchIndex)`：把**仍有 tab 的窗格**按原 `batch` 升序紧凑重排到 `0..K-1`，再按"剩余窗格数 K + 原布局方向"降级布局（K=1→`c1`、2→`c2`/`r2`、3→`c3`/`r3`、4→`c2x2`）；**重排必须在 `setLayout` 之前**（`setLayout` 会收拢越界 batch）。
2. `layout.jsx` 透传 `isEmpty`（`tabsBatch[i]` 为空）+ `onClosePane` → `tabs/index.jsx` → `no-session.jsx`；
3. `no-session.jsx` 在 `store.layout !== 'c1'` 且本窗格为空时显示 **text 按钮「关闭此窗格」**，用 `Popconfirm` 预告目标布局（"关闭后剩余窗格将重排为三列布局"）；
4. 文案走词条补丁层（`locales-extra.js`），不依赖外部语言包。

### 2.2 可选：自动关闭（§4.6 配置开关）

`autoCloseEmptyPaneWhenLastTabClosed`（默认 **关**）：关掉某窗格最后一个 tab 时自动收起该窗格。风险是"只想关 tab，分屏结构却被改"，故默认不启用。

## 三、需求 3：树面板圆角与滚动条

### 3.1 现状

- `.db-tree-panel`（`db-session.styl:25-34`）：`overflow auto` + `border 1px solid var(--border)` + `border-radius var(--radius-sm)` + `padding 4px`；
- 全局滚动条（`src/client/css/basic.styl:13-29`）：`::-webkit-scrollbar` 宽 7px、thumb 为**直角** `var(--primary)`；
- 于是圆角容器里是直角 thumb，滚动到两端时 thumb 与容器圆角相切/被裁，形成"容器圆角、滚动条不圆角"的割裂感（用户反馈）。

### 3.2 方案

| 方案 | 内容 | 评价 |
| --- | --- | --- |
| **A（推荐）** | 保留容器圆角，**滚动条也圆角**：`.db-tree-panel::-webkit-scrollbar-thumb { border-radius 3px }`，并让 thumb 与圆角留出间距（`background-clip content-box` + 透明 1px 边框，或加 `padding` 语义的 `border`） | 与全局设计系统（面板多用 `--radius-sm`）一致 |
| B | **去掉容器圆角**：`.db-tree-panel { border-radius 0 }` | 一行改动，但破坏面板圆角一致性 |
| C | 容器圆角 + 滚动条整体隐藏（`width 0`） | 键/表很多时无法滚动，不可取 |

> 若选 A，建议**只改树面板**，不进 `basic.styl` 全局（避免影响终端/文件列表等既有滚动条观感）。

## 七、一句话总结
