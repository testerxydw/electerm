## §3 待拍板：有图标也染页签颜色（两个候选方案）

### §3.0 触发条件（两方案通用）

- **仅当页签显式设置过颜色（`tab.color` 存在）才染页签本体**。未设颜色的页签不参与页签本体染色——默认蓝只兜底编号徽标，不扩散到整个页签，否则所有素色页签都会带蓝条，颜色失去辨识意义。
- 染色与有无图标无关：纯颜色页签、图标+颜色页签、激活页签均按同一规则染色（这正是"有图标也染页签颜色"的本意）。
- 实现口径：页签颜色经 CSS 变量下传——`tab.jsx` 在 `tab.color` 存在时给根元素加 `tab-colored` 类并内联 `style={{ '--tab-user-color': tab.color }}`；样式全部落在 `tabs.styl`，组件不写颜色判断散落 if。

### §3.1 方案 A：下缘 2px 全饱和色条

页签下缘叠一条 2px 的全饱和页签颜色条，内容区（图标 / 标题）完全不动。

- 默认态：`box-shadow: inset 0 -2px 0 var(--tab-user-color)`。
- 激活态叠加：激活页签已有顶部 2px 品牌渐变条 + 1px 描边（[tabs.styl:83](../src/client/components/tabs/tabs.styl#L83) 附近），双阴影并列即可——`box-shadow: inset 0 0 0 1px …, inset 0 -2px 0 var(--tab-user-color)`，上条是品牌色、下条是页签色，互不覆盖。
- 优点：图标清晰度零风险（不碰内容区背景）；改动最小（1 条声明 × 2 态）。
- 代价：颜色表达较弱，页签较窄时色条易被忽略。

### §3.2 方案 B：14% 淡染背景 + 下缘 2px 色条

在方案 A 基础上，页签背景再掺 14% 页签颜色淡染。

- 三态淡染（各自掺进对应表面色，保证与主题派生色相容）：
  - 默认：`background-color: color-mix(in srgb, var(--tab-user-color) 14%, var(--surface-0))`
  - 悬停：掺进 `var(--hover-bg)` 同底
  - 激活：掺进 `var(--surface-1)` 同底（注意激活态现有 `background-image` 顶部渐变条不受影响，`background-color` 与其分层并存）
- 图标清晰度论证（回应"整块染色会不会让图标看不清"）：14% 淡染后底色仍接近原表面色（以深色主题为例，`#bf3989` 掺 14% 与原 `--surface-0` 的亮度差 < 8%），多色图标（内置 PNG）对比度基本不变；标题文字走 `var(--text-dark)`，同理不受影响。**被否决的做法**：背景直接用全饱和页签颜色——图标是彩色位图，无法像徽标文字那样按底色自动反白/反黑，饱和底上必然出现同色系看不清的情况；且激活/悬停背景还要再叠一层。草图方案 B 区块附了"14% 淡染 vs 全饱和"图标并排对照，可直观验证。
- 优点：颜色一眼可辨（整签带色 + 下缘实色条双通道）。
- 代价：三态各一条 `color-mix` 声明；极浅色（近白）页签颜色在浅色主题下淡染感知弱，靠下缘全饱和色条兜底，不做自动反色。

### §3.3 边界与不变项（两方案通用）

| 项 | 规则 |
| --- | --- |
| error 页签 | 状态点红色 + 行首刷新键不变；若该页签有颜色，染色照常叠加 |
| processing 页签 | 状态点品牌色脉动不变，染色照常 |
| 钉住页签（图钉） | 图钉位置在徽标后，染色照常 |
| 拖拽插入指示 | `dragover-tab::after` 虚线不受影响（方案 A 走 box-shadow，不占用 ::after） |
| 激活页签 | 顶部品牌渐变条保留，页签色条在下缘并存 |
| 无颜色页签 | 完全不染（§3.0） |
| 颜色取消 | 用户在颜色面板清掉颜色 → 移除 `tab-colored` 类与变量，退回素页签 |

## §4 验收判据（拍板后实机探针口径，沿用 self-test/tab-layout-demo.js 风格）

1. 状态点：`position=absolute / left=2px / top=2px / width=5px`，实测 dx≈2、dy≈2（已有判据，回归）。
2. 编号徽标：行内首元素；底色 = 所设颜色；无颜色页签底色 = 默认蓝（已有判据，回归）。
3. 染色触发（新增，按拍板方案）：
   - 显式颜色页签（含图标页签）：`.tab` 带 `tab-colored` 类，computed style 命中对应染色声明，实测下缘色条像素色 = 所设颜色；
   - 未设颜色页签：无 `tab-colored` 类，背景/阴影与素页签一致；
   - 清除颜色后：`tab-colored` 类消失。
4. 激活叠加（新增）：有颜色激活页签同时存在顶部品牌渐变条与下缘色条，两者色值互不覆盖。
5. 图标清晰度（方案 B 时新增）：图标+颜色页签截图与素底截图并排人工复核 + 对比度抽测（图标主色 vs 淡染底 ≥ 3:1）。
