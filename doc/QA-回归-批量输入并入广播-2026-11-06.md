## 6. 边界审查发现（`sendBroadcastOnce` / `sendOnceToTargets`）

1. **闸门不对称（判定：非 Bug，但需产品确认）**
   `sendOnceToTargets` 的 `includeSource` 分支只检查 `disposed` 与 `_passwordPromptDetected`，**不套 `isMirrorableData`（OSC/DCS/非字符串）闸门**；目标侧由 `mirrorInput` 拦截。因此 `data` 为 OSC 应答时：目标零扇出，主控仍本地执行。
   依据 `term-broadcast.js` 注释「OSC 应答只对本地有意义」——主控即本地终端，且 `sendBroadcastOnce` 的 `data` 恒为 `trim(用户输入) + '\r'`（用户在 TextArea 手工粘贴 ESC 序列属极端边缘），故**不判为源码 Bug**。已写观察用例锁定当前行为并加注释；若后续决定统一闸门，需同步更新该用例与本报告。
2. **主控密码期不阻断目标扇出**：`sendOnceToTargets` 未向 `mirrorInput` 传 `passwordPrompt`，主控密码提示不会阻止命令发到其它目标；但每个目标自己的 `_passwordPromptDetected` 会逐个跳过，主控自身（includeSource 时）也被跳过。语义合理。
3. **不置持续态**：`sendOnceToTargets` 用临时 `state: { on: true, … }` 借 `mirrorInput` 唯一扇出点，函数内**不引用** `store.broadcast` / `setBroadcast`；store 侧发送前后 `broadcast` 快照一致、`on` 保持 `false`。测试同时用「行为断言 + 源码静态断言」双保险。
4. **命令规范化**：`text = typeof cmd === 'string' ? cmd.trim() : ''`，`data = text + '\r'`，历史存 `text`；多行内部换行保留、首尾空白被裁。非字符串一律拦截。
5. **无目标策略**：`!targets.length && !includeSource` → `broadcastNoTarget`；`includeSource=true` 时允许「只发主控」，`sent=['src']` 并正常收尾。`sent.length===0`（目标全断连/密码期）→ `broadcastOnceNoTarget`，不写历史、不关弹层、不 toast。
6. **持续广播中拒绝**：直接 `broadcastOnceBlocked`，不进入扇出、不改任何状态。
7. **文案键**：git diff 显示本次实际新增 **12 个**键（任务书写 11 个），`en` / `zh_cn` 各 1193 键、**集合完全一致（0 单侧漏键）**，12 个键均被 `broadcast.js` / `broadcast-modal.jsx` 实际引用，`{n}` 占位符两侧一致。另新增的 `localMonitorUnavailable` 属于其它需求，不在本范围。
8. **周边契约**：`mobile.styl:123` 改由 `.broadcast-modal .ant-modal-body` 消费 `var(--bottom-reserved-h, 0px)`；`tab-select.jsx` 保留默认导出 `TabSelect`，`ai-chat.jsx:4` 依赖有效；`footer-entry.jsx` 已无批量输入展开/发送逻辑；`bi-full` 等旧样式类全仓库无残留。
