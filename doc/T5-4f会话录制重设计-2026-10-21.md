## 0. 背景

T5-4e 文件定位已修好。用户反馈三点：

1. cast 文件满屏转义符，希望输入也能录、内容可配置；
2. 录制与既有「终端日志」重复 → 统一入口；
3. 日志存储目录也要统一，并能在终端日志页「打开日志目录」（文字按钮 / 文档图标）。

本版按拍板方向：**一个入口 = 右侧「终端日志」页；一个目录 = 所有会话日志与录制文件同处**。

## 1. 根因：cast 里为什么全是转义符（固有形态，非 bug）

cast 是 asciinema v2 格式 = 终端字节流的时间戳重放，记录的就是终端协议本身：

| 内容 | 例子 | 来源 |
|---|---|---|
| 颜色/光标序列 | `\u001b[32m` `\u001b[2J` | 终端输出固有 |
| shell integration | `\u001b]633;E;...\u0007` | electerm 注入的 OSC 633（噪声最大头） |
| 逐 chunk 碎片 | `[2.294,"o","h"]` | 输出按到达分片，一行被拆多条 |

asciinema 官方录出来同样如此——不是给人直读的，是给播放器渲染的。可读归档由纯文本日志承担。

## 2. 同类软件参照

| 软件 | 产物 | 输入录制 | 可读性 |
|---|---|---|---|
| asciinema | .cast 重放 | `--stdin` 可选（i 事件） | 播放器渲染，源文件含转义 |
| script (util-linux) | typescript 纯文本 | 默认录输入+输出 | 含转义，`col -bp` 清理后可读 |
| TermRecord | 自包含 HTML | 否 | 渲染后 HTML，无可读源文件 |

## 3. 现状盘点：两套录制 + 两个目录

| 维度 | 既有 term-log（上游） | T5-4 cast 录制 |
|---|---|---|
| 入口 | 右键 `onRecord/onStopRecord`；右侧「终端日志」页 `saveTerminalLogToFile` 开关 | 顶栏按钮 + `⌘R` |
| 文案 | `e('record')` / `e('stopRecord')` | **同一组 key** |
| 产物 | `.log` 纯文本（headless xterm 逐行渲染） | `.cast` asciinema v2 字节流 |
| **目录** | `config.sessionLogPath`，空则 `appData/electerm/session_logs` | **`app.getPath('downloads')`** |
| 时间戳 | 可选行首 `[HH:MM:SS]` | 每事件相对秒 |
| 转义 | 天然没有 | 原始字节流 |
| 可回放 | 否 | 是 |
| 实现层 | 主进程 `SessionLog`（`session-base.js:119`） | 渲染层 `SessionRecorder` + 主进程 `ipc.js:238` |

结论：

- UI 同名不同物 → 统一到「终端日志」页；
- 目录分居 Downloads / 配置目录 → 统一到一个目录；
- 上一版的「新增纯文本 log + ansi-filter」= 重造 term-log，**已删除**。

### 4.3 存储目录统一

**唯一目录**（两种产物同处）：

```
config.sessionLogPath   （既有配置项，非空时优先）
  └─ 空时默认： app.getPath('appData')/electerm/session_logs
     Linux 实际为  ~/.config/electerm/session_logs
```

- 文本日志：`<logName>.log`
- cast 录制：`electerm-rec-YYYYMMDD-HHMMSS.cast`
- cast 不再落 `~/Downloads`（行为变更；旧文件不迁移、不删除，仅提示新目录）
- 目录不存在时自动 `mkdir -p`（创建 cast 文件与打开目录两个入口都兜底）

主进程侧新增一个**局部**目录解析函数（仅 `ipc.js` 内使用，不跨模块抽象）：

```js
const getSessionLogDir = () => {
  const config = globalState.get('config') || {}
  return config.sessionLogPath || join(app.getPath('appData'), 'electerm', 'session_logs')
}
```

`createRecordFile` 改用它取目录；新增 `openSessionLogDir`（mkdir + `shell.openPath`）注册为 asyncGlobal。

- `[t,"i","keys"]` 事件（asciinema `--stdin` 同款）。
- 开启时首次 toast 警告；密码避录默认兜底。
- 文本日志不录输入（主进程 SessionLog 只取渲染后的输出行）。

### 4.9 密码自动避录

- 复用 attach-addon-custom 已有 `_passwordPromptDetected` / `_onEchoCheckTimeout`：
  密码提示 → `recorder.pause()`；回车 / Ctrl+C / 200ms 无回显 → `resume()`。
- 仅影响 cast（文本日志本就不含密码输入）。

## 5. 边界与风险

- **目录变更**：cast 从 Downloads 迁到配置目录，属行为变更；需在变更说明注明旧文件不迁移。
- `openSessionLogDir` 用 `shell.openPath`（Linux 走 xdg-open），失败仅日志不弹错。
- 页面靠 `refs.get('term-' + pid)` 读状态 + 100ms 轮询兜底；cast 状态直接读 store，不叠加轮询。
- 顶栏录制控制仅在有终端实例的页渲染（`inTerminalTab && hasShellSession`）。
- 右键 `onRecord` 改为打开面板会改变既有交互（原本直接弹保存框）；文本日志区仍提供开关，能力不丢。
- 两条链路同时开时停录通知重名（都叫 `stopRecord`），需合并为一条。
- OSC 剥离默认开，调试 shell integration 时需临时关。
- 兼容：`recordInput=false` 默认，cast 事件格式向后兼容。
