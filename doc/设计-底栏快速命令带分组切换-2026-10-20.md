# 设计：底栏快速命令带（常显 + 分组切换，默认全部）

> 状态: 已实施（`fdd3fbbc` 首版 + `6cd9ace9` 布局修复，组件 `footer/quick-cmd-strip.jsx`；v1"弹层内嵌"方向已废弃——需求是显示在底栏本身）
> 涉及文件: `footer/footer-entry.jsx`、新增 `footer/quick-cmd-strip.jsx`、`footer.styl`、`common/constants.js`（新增 ls key）

## 1. 需求

- 快速命令直接显示在**底栏**上，填充批量输入框之后的中部空白区（`.terminal-footer-center`，flex-grow 1）
- 可在底栏上**切换显示的命令分组**，默认显示所有
- 充分利用底栏空白空间，不新增弹层

## 2. 现状依据

- 底栏结构：左区状态｜中部（批量输入触发器 + 空白 `.terminal-footer-center`）｜右区全局动作，高 30px
- Q 按钮（`renderQuickCommands`，footer-entry.jsx:86）管管理入口：浮动框（`openQuickCommandBar`）或右面板页签（`quickCommandsInRightPanel` 模式）——本设计与它互补不冲突
- 数据：`store.quickCommands`（`name`/`command`/`labels[]` 分组），`store.quickCommandTags` getter（uniq 标签）现成
- 执行链路现成：`store.runQuickCommand(cmd, inputOnly, tabId)`（store/quick-command.js:60）；现有调用模式 `runQuickCommand(cmd)` + `addCmdHistory(cmd)`（common.js:784-785）

## 3. 方案

### 3.1 布局（底栏中部命令带）

```
┌─ 底栏 30px ──────────────────────────────────────────────────────┐
│ 状态区  B批量输入  [组▾] ›cmd1› ›cmd2› ›cmd3› …(横向滚动)  🛠 全局 │
└──────────────────────────────────────────────────────────────────┘
```

- 命令带位于批量输入触发器右侧、右区分隔线左侧，占满剩余空白
- 分组切换器固定在带左端：**左右箭头循环切换**（`‹ 组名 ›` 形态，非下拉）——序列 `全部 → 组1 → 组2 → … → 全部` 循环，左右键等价点击；当前组名始终可见
- 胶囊：12px 字号、高 22px、`--radius-xs`、ellipsis 截断 + title 悬浮完整命令
- 命令多时带内横向滚动（`overflow-x: auto`，隐藏滚动条，滚轮横滚 `wheel` → `scrollLeft`）；右缘渐隐遮罩提示可滚

### 3.2 分组选择（定稿：箭头循环切换）

- 组序列 = `['全部', ...store.quickCommandTags]`，默认"全部"，**无设置项、无下拉**
- 过滤：`全部` → 全量；否则 `q.labels.includes(tag)`
- 持久化：`constants.js` 新增 `quickCmdBarTagKey`（ls 存标签字符串，空串 = 全部），参照 `quickCommandsInRightPanelKey`（constants.js:166）现有模式
- 选中分组被删后：渲染层兜底显示空态（"该组暂无命令"），不自动改持久化值

### 3.3 点击行为（复用现成链路）

- 左键命令 = `store.runQuickCommand(cmd)` + `store.addCmdHistory(cmd)`（与 common.js:784 现有模式一致），发送到当前激活终端
- 右键命令（增强项，可后置）= 填入旁边批量输入框（`batchInput` 联动），不直接发送

### 3.4 显隐与收缩

- 渲染 gate 与批量输入一致：`inActiveTerminal && !isMobile && store.quickCommands.length > 0`（footer-entry.jsx:378 同款条件）；无命令/无会话/移动端自动隐藏，底栏回归纯空白
- 窄窗：带 `min-width: 0` + 内部滚动；左区状态可被压缩截断的现有规则不变，右区永不缩不变
- 与左区/右区间距沿用 `.terminal-footer-unit` 的 `margin-left: 10px` 节奏

### 3.5 实现边界（最小修改）

- 新增一个子组件 `footer/quick-cmd-strip.jsx`（footer 目录已有 batch-input.jsx/tab-select.jsx 子组件惯例）；`renderQuickCmdStrip()` 在 footer-entry.jsx 中部挂载，与 `renderBatchInputs()` 并列
- store 零改动：只读 `quickCommands`/`quickCommandTags`，调既有 `runQuickCommand`/`addCmdHistory`；组选择状态留组件本地 + ls，不进 mobx store
- footer.styl 新增 `.quick-cmd-strip` 一节，复用现有 token（`--radius-xs`/`--hover-bg`/`--dur-1`/`--text-dark`）
- 不动 Q 按钮、浮动框、右面板页签、批量输入、quickCommands 数据结构

## 4. 边界场景

| 场景 | 行为 |
|---|---|
| 无快速命令 | 整条带不渲染 |
| 命令无 labels | 分组切换器隐藏（仅"全部"一档），带显示全部 |
| 选中分组被删 | 空态提示，不自动改持久化 |
| 命令超长/多行 | 胶囊单行 ellipsis + title；发送保持原文（runQuickCommand 既有行为） |
| 激活 tab 切换 | 带内容不变（全局命令），发送目标跟随当前激活终端 |
| 移动端 | 不渲染（mobile 底栏空间由批量输入/B 按钮优先） |
| 命令带 hover 与点击热区 | 胶囊间距 6px，点击热区即胶囊本体，不与批量输入/右区重叠 |

## 5. 定稿决策（用户已拍板，2026-10-13）

1. **常显开关：不做**——不新增设置项，满足 gate 即常显（`inActiveTerminal && !isMobile && quickCommands.length > 0`）
2. **右键填入批量输入：后置**——首版仅左键发送，右键增强留待后续
3. **分组切换器：左右箭头循环切换**——`‹ 组名 ›` 形态，非下拉 Select（已同步 3.1/3.2 节）
