RDP / VNC / SPICE 现在把操作按钮排在连接信息左边，与终端页、数据库页相反。本页给出跨七类页面的共同契约与逐页改法。

一、共同规范：一条顶栏只有三个区

从左到右读得通 —— 我在哪（A）→ 对它做什么（B）→ 对这个窗口做什么（C）。

A 信息user@10.0.0.8已连接SSHzsh 5.9 · ↑2.1k ↓8.4k B 操作重连跟随保活广播录制 C 窗口
区放什么规则
A 连接 / 上下文 状态点 · 目标（user@host:port / 引擎 · 库 · 用户 / 本地）· 类型徽标 · 运行态元信息 永远是栏内最左；缺字段的那一段不渲染，不留半截 @ 或 :0。身份文本 12.5px + 600 字重，徽标 10px 胶囊，元信息 11px 等宽。
B 会话操作 重连、显示控件（分辨率 / 选屏 / 缩放 / ctrl⇄cmd）、页面专有动作（SFTP 导航刷新、DB 只读 / 生产 / 刷新、终端跟随 / 保活 / 广播 / 录制） 紧接 A 之后。归属判据：这个动作改变远端会话吗？改变（重连、分辨率、缩放、上传下载、DB 查询、终端录制）留 B；只改变本地窗口（查找、全屏）进 C。栏内图标统一 16px，控件一律 size="small"，压在同一个 32px 行盒里；组内用 1px 分隔线切语义。
C 窗口动作 查找 → 全屏 → ⋮ 菜单 margin-left: auto 贴右，顺序七页一致。⋮ 内只放动作（退出全屏、Send Ctrl+Alt+Del），不放设置。
B 组内顺序 先「让画面/连接回到正轨」再「调显示」再「传数据」：
RDP：重连 → 分辨率 + 编辑 → 缩放 → ctrl⇄cmd → 上传 / 下载 / help。
VNC：重连 → 选屏 → 缩放。SPICE：重连 → 缩放。
终端：跟随 → 分屏 → 保活 → 广播 → 录制 → 换行。数据库：生产标记 → 临时解除 → 只读 → 系统库 → 刷新。
高度 / 换行 单点 --session-bar-h: 32px、--session-bar-pad-x: 10px。放不下时整条 flex-wrap，退让顺序固定：C 保持贴右 → B 先换第二行 → A 的元信息最后换。页面专有栏（DB / web / SFTP）不换行，用省略号 + tooltip 兜。
全屏 整条 display: none，只留右上角浮层 ⋮（现有行为保留，栏内不留半个死图标）。

四、实施落点（已按本草图落地）

位置改动
共享壳左栏顺序改为 SessionInfo → 重连 → displayItems，A 与 B 之间补 1px 竖线；条目间距收进 column-gap 8px，三端不再写 mg1l / mg2l / mg1r。
RDPB 组内改为 分辨率 + 编辑 → 缩放 → ctrl⇄cmd → 上传 / 下载 / help（文件传输原排在最前）。
图标字号16px 规则从子选择器改为后代选择器（Tooltip 套两层时原来选不中，文件传输图标实际一直是 14px）；Select 箭头显式 inherit 不受影响。
SFTP面板标题行改左对齐：身份串（走 formatConnInfo）在左、刷新贴右；地址行保持浏览器习惯（导航在 URL 之前）。
终端 / 数据库已符合 A→B→C，未改动，只作为口径来源。

验证：remote-session-bar.spec.js 跟齐新契约（左栏顺序 / RDP 组内顺序 / column-gap 单点 / sftp 标题顺序 / 字号选择器）；self-test/topbar-order-probe.js 编译真实 .styl + 真实 antd DOM 骨架在 headless Edge 实测，9/9 通过（条高 32px、条目同中线、竖线 1×16px、图标 16px、箭头 12px）。

落点：契约收在 SessionShell（RDP / VNC / SPICE 共用，改左栏顺序）与 sftp-entry.jsx 的面板标题行两处即可。终端页 SessionControl、数据库页 .db-head 已符合，只需对齐状态点与徽标口径；web 页 URL 栏是可编辑的 A 区，保持浏览器习惯（导航在前）不动。
