## 三、通用验收标准（每轮）

1. **编译**：`grep -q "Build failed" <log>` 必须为「成功」；产物 CSS/JS 或运行时计算样式已更新；
2. **自测**：CDP 取**运行时真实值**（不只看截图）；必要时像素量化（颜色/尺寸）；
3. **回归**：主界面（标题栏/标签栏/图标栏/面板/终端/快捷键条/footer/状态栏）无错位；
4. **记录**：`UI-自测报告.md` 追加本轮（改动表 + 验证 + 局限 + 计划）；
5. **提交**：一个轮次一个提交，含报告与截图。

### 结论

- **纯前端可继续做**：E（首页空态）、F（图标顺序，默认值）、G（状态点/类型标签）、H（transfer 页）；
- **需数据/功能支撑**：A（状态栏三段）、B（shell）、C（REC）、D（气泡需改渲染）。

## 四、风险与约定

| 项 | 约定 |
| --- | --- |
| Stylus | 含 `in` 的 `color-mix(...)` 必须 `unquote()`；多层 background 整体 `unquote()` |
| CSS 变量 | 等宽字体用 `--font-mono`（项目无 `--mono`） |
| 虚拟滚动 | 会话树行高改动必须同步 `tree-list-layout.js` 的 `treeRowHeight` |
| 面板联动 | 栏宽只用 `--left-side-bar-width`，禁止硬编码 |
| 运行验证 | 必须 `pkill -f "work/app"`（含 server.js）后重启 + `--disable-http-cache` |
| 数据缺失项 | 明确标注「需数据管线」，不用假数据填充 |
