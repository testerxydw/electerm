electerm 美化深度设计预览 · v4「Tinted Console」品牌浸染控制台

设计主张：整个应用的外壳不再是「中性灰黑」，而是被品牌蓝 4% 级别浸染——深色下呈现独有的蓝黑气质，浅色下自动变为蓝白。 激活态用光晕而不是平涂，状态用色底芯片而不是变文字色，浮层有描边环 + 双层阴影的层级感。 依旧零布局位移、零类名改动、全部在红线内（新增 CSS 属性仅 transform 与 background-image 渐变）。

「改造后」面板的 hover / 光晕 / 上浮都是真实 CSS，把鼠标放上去体验

设计语言四要素

v4 新增层

① 品牌浸染色阶（4 级）

s0s1s2s3

s0=4% primary+main-dark（标签栏/图标栏）· s1=2%+main（内容区）· s2=main-light（浮层）· s3=6% text+main（更高浮起）。色相跟着主题走，浅色下自动变蓝白。

② 光晕激活态

平涂（v3） 光晕（v4）

激活 = 1px 主色环 + 16px 柔光。焦点、选中、按下共用同一语言（--glow 一个 token）。

③ 状态色底芯片

✓ 已完成 12 ⏳ 传输中 ✕ 失败 2

14% 色底 + 同色文字 + 30% 同色描边。传输状态、消息通知、监控条全部统一。

④ 渐变强调线 + 等宽点缀

激活标签顶部、面板表头用 primary→透明渐变线；路径 / 大小 / 次数 / 版本号用等宽字体——终端应用的辨识度。

⑫ v4 的安全边界（与 v3 相同的红线）

零风险声明
  • 全部效果只用了 color / background / background-image / box-shadow / border-radius / transform / font-family —— 零布局位移（transform 由合成器处理，不参与布局）
  • 色阶与光晕全部 color-mix 从既有 12 个主题 key 派生 → 310 个 iTerm 主题 + 浅色自动适配，约束 A（白名单）零触碰
  • 零类名改动、零 DOM 增删 → e2e 类选择器与可见性断言不受影响
  • 等宽字体仅作用于新增声明（大小/次数/版本号），不改全局字体栈；CJK 回退仍按 §3.8 单独做
  • 唯一新增的"动效"是 hover 上浮（transform）与既定 120ms 过渡，均在 prefers-reduced-motion 兜底内
  • 范围外仍不改：--success 浅色 1.61:1（既有缺陷，单独 issue）、--text-light 语义反转、布局数值
